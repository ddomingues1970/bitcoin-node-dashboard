# Run Record — Mempool UI Rework

- Run time: 2026-11-20 21:03:51 -03:00
- Objective: diagnose the empty Blocks view and incomplete Mempool view; correct the RPC data path and deliver a more useful local-only interface.

## Diagnosis

- The prior adapter parsed every `bitcoin-cli` stdout as JSON. `getblockhash` returns an unquoted 64-character hex scalar, so parsing failed and recent blocks were discarded.
- Bitcoin Core 32.1 exposes summed BIP 141 virtual size as `getmempoolinfo.bytes`; the prior parser only read `vsize`, which is not present in the live response.
- Fee estimates are BTC/kvB. The prior UI divided by 1,000 but did not convert BTC to satoshis, producing `0.00 sat/vB`. Missing/non-positive estimates also need to remain unavailable.
- The local read-only `getblocktemplate` query succeeded. It completed in about 0.23 seconds and returned about 6.9 MB during measurement. The UI now uses it under a three-second RPC timeout, four-second process guard, streaming 8 MB output cap, and 55-second in-memory aggregate cache.

## Decisions and delivered changes

- Added a strict parser for bitcoin-cli bare hash scalars and sanitized diagnostic categories for RPC unavailable, timeout, unsupported method, pruned data, malformed result, active-chain mismatch, and output limit.
- Blocks retains up to six successfully verified cards when another card fails. Cards are checked against active-chain height and positive confirmations; selected details return up to 100 transaction IDs.
- Mempool uses local aggregate info and fee estimates, an explicitly labeled local candidate template, and eight template-selected fee-rate bands. Template transaction hex and IDs are discarded before constructing the API response. This is not a full mempool histogram or a prediction of a pool's block.
- Reworked Mempool into two desktop groups: local candidate/fee bands and recent confirmed blocks. Added local pool totals and minimum fee context. Fee bands explain their fee-rate/color and virtual-size mapping.
- Omitted incoming-transaction history because sampled mempool count deltas include removals and would not represent arrivals honestly.
- Preserved the loopback listener and existing token/Origin-confirmed shutdown flow.
